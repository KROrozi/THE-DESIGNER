# 더 디자이너

나는 어떤 디자이너인가? 「더 커뮤니티」 사용자 테스트를 패러디한 디자이너 성향 테스트.

- **사상** (시즌 1 구조, 4지선다 64문항): 권한 · 영향 · 도구 · 원본
- **작업** (시즌 2 구조, O/X 42문항): 동기 · 방법 · 형태

## 문항·결과 수정
`index.html` 안의 `✏️ 편집 영역`에서 `THOUGHT`(사상)와 `WORK`(작업)만 고치면 됩니다.
- `questions`: `[영역 번호, 방향, "문장"]` — 방향 1은 동의할수록 왼쪽 성향, -1은 오른쪽 성향
- `players`: 결과 코드와 글자가 가장 많이 겹치는 플레이어가 매칭됩니다

## 크레딧
- 폰트: Cafe24 PRO Slim (카페24), Noto Sans KR, IBM Plex Mono / IBM Plex Sans KR (Google Fonts)
- 웨이브 오리지널 「사상검증구역: 더 커뮤니티」, 「더 커뮤니티 2: 보이지 않는 손」의 비공식 패러디이며 원작과 관련이 없습니다.
